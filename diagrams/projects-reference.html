eshop-full — projects reference

Twenty-one projects, one migration order: foundation, then domain, then workers, then frontends, then orchestration.

Every project below, in the order it's actually being built — not upstream's original list order. eShop.slnx/eShop.Web.slnf only ever list what exists on disk today, so dotnet build and CI never try to build a project that isn't real yet. See System Architecture for the same information as a layer diagram, and todo.md's "Still to do" table for the live flat list.

Identity.API

Done

Catalog.API

Product catalog — read-heavy, scales independently of everything else. Real v1/v2 API surface, AI embedding-based semantic search, pagination/filtering. 45 tests, including a real upstream validation bug (UpdateItemV1's id check is dead code — CatalogItem.Id is a non-nullable int) found and documented, not silently fixed.

Done

Basket.API

Redis-backed ephemeral cart state — pure gRPC, plus a genuinely new Grpc.AspNetCore.Web endpoint so WebApp/WebBFF can consume it directly. Two named Kestrel endpoints (HTTP/2 native gRPC, HTTP/1.1 gRPC-Web) since Kestrel can't multiplex both on one port without TLS — proved both failure modes directly before picking that fix.

Done

Ordering.Domain

Domain model — the "D" in a domain-driven design split across three projects. Two aggregates (Order, Buyer), 7 domain events, a shared SeedWork kit.

Done

Ordering.Infrastructure

EF Core persistence for the order aggregate — a real Repository layer here, unlike Catalog.API's deliberate no-repository call.

Done

Ordering.API

The order-placement API surface — MediatR CQRS with a 3-stage pipeline behavior chain (Logging → Validator → Transaction), the same Decorator shape EventBusKafka's split already established, just expressed through MediatR's own extension point. Pinned to MediatR 12.5.0 (13+ moved to a commercial license).

Done

Webhooks.API

Outbound webhook notifications for third-party integrations — confirmed textbook Observer pattern over HTTP. A real no-op upstream event handler and a dead exception class found and kept, documented rather than silently fixed.
